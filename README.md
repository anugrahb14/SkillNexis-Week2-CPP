# Skill Nexis - C++ Week 2

This repository contains the C++ programming assignments and mini project completed for Week 2 of the Skill Nexis C++ Programming Internship.

## Week 2 Assignments

### 1. Factorial Using a Function
A C++ program that uses a user-defined function to calculate the factorial of a number.

### 2. Reverse Array Using a Function
A program that reverses the elements of an array using a user-defined function.

### 3. Count Vowels in a String
A program that counts the number of vowels in a given string.

### 4. Bubble Sort
A program that sorts array elements in ascending order using the Bubble Sort algorithm.

## Mini Project

### Student Report Generator

A console-based student report generator using functions and arrays.

Features:
- Student name input
- Marks for five subjects
- Total marks calculation
- Average calculation
- Grade calculation

## Concepts Used

- C++ Functions
- Arrays
- Loops
- Conditional Statements
- String Handling
- Bubble Sort
- Console Input/Output

## Project Files

- `factorial.cpp` — Factorial using a function
- `reverse_array.cpp` — Reverse array using a function
- `count_vowels.cpp` — Count vowels in a string
- `bubble_sort.cpp` — Bubble Sort
- `student_report.cpp` — Student Report Generator
